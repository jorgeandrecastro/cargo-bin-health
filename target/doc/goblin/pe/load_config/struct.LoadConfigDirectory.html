Expand description

Represents the 32/64-bit Load Configuration directory structure of a PE file.

This structure contains information related to the loading configuration of a PE (Portable Executable) file. It provides details for various configuration settings that the operating system loader may use when loading the PE file into memory. This structure is marked as non_exhaustive, meaning that future versions of the PE format may include additional fields that are not present in the current version of this structure.

§Notes

This structure may grow in future versions of the PE format, so be cautious when working with it, as some fields may not be available or relevant for all versions of PE files.
