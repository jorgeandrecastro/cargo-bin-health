Convert a MIPS64 little-endian r_info value to the standard ELF64 format.

MIPS64 ELF uses a non-standard relocation info layout:

  • r_sym (32 bits) | r_ssym (8 bits) | r_type3 (8 bits) | r_type2 (8 bits) | r_type (8 bits)

On little-endian systems, when this struct is read as a single u64, the byte order causes the fields to be scrambled compared to the standard (sym << 32) | type layout. This function rearranges the bytes so that the standard r_sym and r_type functions return correct values.

See the MIPS64 ELF ABI and LLVM’s implementation for reference.
